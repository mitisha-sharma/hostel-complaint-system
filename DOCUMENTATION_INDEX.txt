🔌 API ENDPOINTS QUICK REFERENCE
================================================================================

AUTHENTICATION:
  POST   /api/auth/login              - Login
  POST   /api/auth/register           - Register

COMPLAINTS (Main Feature):
  POST   /api/complaints/raise        - Raise complaint
  GET    /api/complaints              - Get all (filtered by role)
  GET    /api/complaints/:id          - Get details
  PUT    /api/complaints/:id/assign   - Assign to staff
  PUT    /api/complaints/:id/status   - Update status
  PUT    /api/complaints/:id/reject   - Reject
  GET    /api/complaints/stats/overview - Dashboard stats

USERS:
  GET    /api/users                   - All users
  GET    /api/users/role/:role        - By role
  GET    /api/users/profile/me        - Current user

STAFF:
  GET    /api/staff                   - All staff
  GET    /api/staff/department/:dept  - By department

Full details: backend/README.md
