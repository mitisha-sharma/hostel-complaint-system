QUICK START GUIDE - Hostel Complaint System
============================================

STEP 1: Start MongoDB
=====================
Open PowerShell and run:
  mongod

If mongod is not recognized, install MongoDB Community Edition first.
Download from: https://www.mongodb.com/try/download/community


STEP 2: Seed Database (Only First Time)
========================================
Open NEW PowerShell window and navigate to project:
  cd c:\Users\abhis\Documents\Project\hostel-complaint-system\backend
  node seed.js

You should see:
  ✓ MongoDB connected for seeding
  ✓ Cleared existing users
  ✓ Users created: 5
  ✓ Seeding completed successfully


STEP 3: Start Backend Server
=============================
Keep PowerShell window open and run:
  npm run dev

You should see:
  ✓ Server is running on port 5000
  ✓ MongoDB connected


STEP 4: Start Frontend Server
==============================
Open ANOTHER PowerShell window:
  cd c:\Users\abhis\Documents\Project\hostel-complaint-system
  npm run dev

Then open browser and go to:
  http://localhost:5173

TROUBLESHOOTING
===============

Port is already in use?
  Stop-Process -Port 5000 -Force

MongoDB not starting?
  net start MongoDB
  (or install MongoDB Community Edition)

Cannot connect to backend?
  - Check if backend is running on port 5000
  - Check CORS is enabled (already configured)
  - Check token is in localStorage

npm install failed?
  rm -r backend/node_modules
  rm backend/package-lock.json
  cd backend && npm install
