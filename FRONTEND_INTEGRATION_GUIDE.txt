Current File: src/pages/Login.jsx

CURRENT IMPLEMENTATION (Dummy Data):
  Finds user in dummyData.js array
  Doesn't actually authenticate with backend
  No token generation

CHANGES NEEDED:
  Import API: import { authAPI } from '../api/api';
  Replace this:
    const foundUser = users.find((u) => u.email === email && u.password === password);
  
  With this:
    const response = await authAPI.login(email, password);
    if (response.message === 'Login successful') {
      login(response.user);
      // Token is automatically stored in localStorage
    } else {
      setError(response.message);
    }

EXAMPLE CODE:
  const handleLogin = async (e) => {
    e.preventDefault();
    setError("");
    setIsLoading(true);
    
    try {
      const response = await authAPI.login(email, password);
      
      if (response.message === 'Login successful') {
        login(response.user);
        const user = response.user;
        if (user.role === 'student') navigate('/student');
        else if (user.role === 'admin') navigate('/admin');
        else if (user.role === 'maintenance') navigate('/maintenance');
      } else {
        setError(response.message || 'Login failed');
      }
    } catch (err) {
      setError('Connection error: ' + err.message);
    } finally {
      setIsLoading(false);
    }
  };

8. ERROR HANDLING PATTERN
================================================================================

All API methods return JSON responses with:
  - message: String describing result/error
  - data: Actual data (user, complaints, etc.)

PATTERN TO FOLLOW:
  try {
    const response = await apiMethod(...);
    
    if (response.message?.includes('success') || response.data) {
      // Handle success
      setState(response.data);
    } else {
      // Handle error from API
      setError(response.message);
    }
  } catch (error) {
    // Handle network or other errors
    setError('Network error: ' + error.message);
  }

9. TOKEN MANAGEMENT
================================================================================

Token Handling:
  - Automatically stored after login: localStorage.setItem('token', token)
  - Automatically retrieved in API calls: Bearer token in Authorization header
  - Automatically removed on logout: localStorage.removeItem('token')

Token Validation:
  - All protected routes verify token validity
  - Invalid/expired tokens get 401 response
  - Frontend should redirect to login on 401

Check Token:
  const token = localStorage.getItem('token');
  const user = JSON.parse(localStorage.getItem('user'));

Clear Token:
  authAPI.logout(); // Clears both token and user

10. AUTHENTICATION CONTEXT UPDATES
================================================================================

Current File: src/context/AuthContext.jsx

The AuthContext should be updated to use the new token-based system:

Current approach: Store user object in context
New approach: Store user and token, verify token on page load

RECOMMENDED UPDATE:
  export function AuthProvider({ children }) {
    const [user, setUser] = useState(null);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
      // Check if user is already logged in
      const storedUser = localStorage.getItem('user');
      if (storedUser) {
        setUser(JSON.parse(storedUser));
      }
      setLoading(false);
    }, []);

    const login = (userData) => {
      setUser(userData);
    };

    const logout = () => {
      setUser(null);
      authAPI.logout();
    };

    return (
      <AuthContext.Provider value={{ user, login, logout, loading }}>
        {children}
      </AuthContext.Provider>
    );
  }

11. ENVIRONMENT CONFIGURATION
================================================================================

Frontend Configuration:
  Backend API URL is hardcoded to: http://localhost:5000/api

For production, update src/api/api.js:
  Change:
    const API_BASE_URL = 'http://localhost:5000/api';
  
  To:
    const API_BASE_URL = process.env.REACT_APP_API_URL || 'http://localhost:5000/api';

Then create .env file:
  REACT_APP_API_URL=https://your-production-backend.com/api

13. COMMON INTEGRATION ISSUES & SOLUTIONS
================================================================================

Issue: "Cannot POST /api/auth/login" - 404 error
  Solution: Verify backend is running on port 5000
  Check: npm run dev from backend folder

Issue: CORS error - "Access to XMLHttpRequest blocked"
  Solution: Already enabled in backend (server.js)
  Check: CORS middleware is before routes

Issue: Token not persisting across pages
  Solution: Verify localStorage is working
  Check: localStorage.getItem('token') in console

Issue: Unauthorized (401) errors on API calls
  Solution: Verify token is being sent with each request
  Check: Authorization header in Network tab

Issue: Cannot find module 'api/api'
  Solution: Verify filepath is correct
  Use: import { authAPI } from '../api/api';

Issue: Data not updating in real-time
  Solution: Add useEffect with proper dependency array
  Or: Call API again after changes
