API ENDPOINTS REFERENCE
================================================================================

Health Check:
  GET /api/health

Authentication:
  POST /api/auth/login              - Login with email/password
  POST /api/auth/register           - Create new account

Complaints (Main Feature):
  POST   /api/complaints/raise      - Raise complaint (students)
  GET    /api/complaints            - Get complaints (role-filtered)
  GET    /api/complaints/:id        - Get complaint details
  PUT    /api/complaints/:id/assign - Assign to staff (admin)
  PUT    /api/complaints/:id/status - Update status (staff/admin)
  PUT    /api/complaints/:id/reject - Reject complaint (admin)
  GET    /api/complaints/stats/overview - Dashboard stats (admin)

User Management:
  GET /api/users                    - Get all users (admin)
  GET /api/users/role/:role         - Filter by role (admin)
  GET /api/users/profile/me         - Current user profile

Staff Management:
  GET /api/staff                    - All maintenance staff (admin)
  GET /api/staff/department/:dept   - Filter by department (admin)

Full API documentation: backend/README.md
