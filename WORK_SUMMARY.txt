API ENDPOINTS CREATED (15 endpoints)
================================================================================

Authentication:
  POST   /api/auth/login              ← Login user
  POST   /api/auth/register           ← Register new user

Complaints:
  POST   /api/complaints/raise        ← Student raises complaint
  GET    /api/complaints              ← Get complaints (role-filtered)
  GET    /api/complaints/:id          ← Get complaint details
  PUT    /api/complaints/:id/assign   ← Assign to staff (admin)
  PUT    /api/complaints/:id/status   ← Update status
  PUT    /api/complaints/:id/reject   ← Reject complaint (admin)
  GET    /api/complaints/stats/overview - Dashboard stats (admin)

Users:
  GET    /api/users                   ← All users (admin)
  GET    /api/users/role/:role        ← Users by role
  GET    /api/users/profile/me        ← Current user

Staff:
  GET    /api/staff                   ← All maintenance staff
  GET    /api/staff/department/:dept  ← Staff by department

Plus: GET /api/health - Health check
